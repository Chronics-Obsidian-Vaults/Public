# Sovereign Glue
*Wondrous item, minor, legendary*  
![](/Campaigns/Chronics%20of%20the%20Times%20Before/Public/Compendium/items/img/sovereign-glue.webp#right)


This viscous, milky-white substance can form a permanent adhesive bond between any two objects. It must be stored in a jar or flask that has been coated inside with [oil of slipperiness](/Campaigns/Chronics%20of%20the%20Times%20Before/Public/Compendium/items/oil-of-slipperiness.md). When found, a container contains `1d6 + 1` ounces.

One ounce of the glue can cover a 1-foot square surface. The glue takes 1 minute to set. Once it has done so, the bond it creates can be broken only by the application of [universal solvent](/Campaigns/Chronics%20of%20the%20Times%20Before/Public/Compendium/items/universal-solvent.md) or [oil of etherealness](/Campaigns/Chronics%20of%20the%20Times%20Before/Public/Compendium/items/oil-of-etherealness.md), or with a [wish](/Campaigns/Chronics%20of%20the%20Times%20Before/Public/Compendium/spells/wish.md) spell.

*Source: Dungeon Master's Guide p. 200. Available in the <span title='Systems Reference Document (5.1)'>SRD</span>*
