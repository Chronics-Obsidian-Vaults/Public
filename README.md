# Chronics of the Times Before - Public Campaign Wiki

Welcome to the player-accessible campaign wiki for **Chronics of the Times Before**, a D&D 5e campaign set in the world of Cylostra.

## What's Here

This repository contains all canonical campaign information accessible to players:

### 📖 Core Content
- **[Assets/](Assets/)**: Character portraits, visual assets, and campaign imagery
- **[Character Notes/](Character Notes/)**: Player character journals, logs, and personal narratives
- **[Characters/](Characters/)**: Player characters and notable NPCs
  - `NPCs/`: Non-player character profiles
  - `Playable/`: Player character information
- **[Places/](Places/)**: Cities, regions, and geographic locations
- **[Organizations/](Organizations/)**: Factions, guilds, and groups
- **[Events/](Events/)**: Major campaign events and timelines
- **[Time/](Time/)**: Cylostran Calendar system and historical eras

### 📚 Reference Material
- **[Compendium/](Compendium/)**: Complete D&D 5e reference material
  - Backgrounds, bestiary, classes, feats, items, spells, and more
- **[Rules/](Rules/)**: Custom and variant rules for this campaign

### 📝 Session Information
- **[Session Notes/](Session Notes/)**: Summaries of past sessions

## World Setting

**Cylostra** is a custom fantasy world featuring:
- **Cylostran Calendar**: Lunar-based system with 15 months, 3 moons (Neia, Ciliren, Amra)
- **Current Year**: 3996 CE (Current Era)
- **Recent History**: Post-Age of Rending, a catastrophic war that ended in 3962
